## 3. New words
- IP = Internet Protocol
- IPv4 = Internet Protocol version 4
- IPv6 = Internet Protocol version 6
- DHCP = Dynamic Host Configuration Protocol (gives IP addresses automatically)
- Subnet mask: Divides networks into smaller pieces.
- Gateway: the door from my network to the internet
- DNS: Domain Name System. It changes a website name (like google.com) into an IP address.
- Public IP / Private IP: Public: used on the internet. Private: used inside my home network.
