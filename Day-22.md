# Day 22 - PowerShell Basics
Date: Nov 17, 2026

## 1. What I learned
- PowerShell is a tool in Windows for running commands, like the terminal in Linux.
- Get-Process shows all programs currently running on my computer.
- Get-Service shows all Windows services and whether they are Running or Stopped.
- I can send command output into a text file using the > symbol.
- Get-Help shows free, built-in help for any PowerShell command.

## 2. What I did
- I opened PowerShell ISE on my Windows laptop.
- I ran Get-Process. It showed many processes, like chrome, explorer, svchost, and Sysmon64.
- I ran Get-Service. It showed services like Windows Update, Windows Defender, and Task Scheduler, with their status (Running or Stopped).
- I ran Get-Process > process.txt to save the process list to a text file, and opened it in Notepad.

## 3. New words
- PowerShell: a command tool in Windows, like the Linux terminal.
- Process: a running program (for example, chrome.exe).
- Service: a background program that Windows manages (for example, Windows Update).
- Get-Help: shows the built-in help for a command.

## 4. What was hard
- Nothing was hard.

## 5. Explain in 2 sentences
- A process is an active program we open and use, like Chrome running when I open a website. A service is a background task that runs automatically without a window, like Windows Update running in the background even when I don't open anything.
