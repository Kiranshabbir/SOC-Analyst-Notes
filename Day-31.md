## 3. New words 
-  Function: A reusable block of code.
- def: Keyword used to define functions.
- List: Ordered, changeable collection of items.
- Dictionary: Collection storing linked key-value pairs.
- Key: Unique label identifying dictionary data.
-  Value: the data linked to a key in a dictionary.

## 5. Explain in 2 lines 
- A function is a reusable block of code that performs a specific task. A list is an ordered collection of items ([...]), while a dictionary ({...}) stores data as key-value pairs where each unique key points to a specific value.
