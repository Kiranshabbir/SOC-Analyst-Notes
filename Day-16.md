# Day 16 - Linux navigation commands.
Date: Nov 11, 2026

## 1. What I learned
- ls is a command which means show list of all folders and files.
- ls -l is a command which means show details of all folders and files.
- cd is a command which means go and back in the folder or file.
- cp is a command which means copy this file or folder.
- rm is a command which means remove this file or folder.
- pwd is a command which means where I am 
- mkdir is a command which means make folder.
- touch is a command which means make a new file.
