## 1. What I learned
- The man command shows the manual (help) page for any command.
- There are different types of ls, like ls -l (details) and ls -a (hidden files).
- I can make 2 or 3 directories at the same time with one mkdir command.
- I can remove 2 or 3 directories at the same time with one rm command.
- The echo command has different uses, not only showing text.
- The cat command can open more than one file at the same time.

## 3. New words
- man = manual (shows help for a command)
- mkdir folder1 folder2 folder3: makes 3 folders at once
- rm -r folder1 folder2: removes multiple folders at once
- cat file1 file2: shows the content of 2 files together
