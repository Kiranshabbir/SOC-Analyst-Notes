## 2. Commands I remembered without help
- pwd: Prints the full path of the current working directory.
- ls: Lists the files and folders inside the current directory.
- cd: Changes your current working directory to a specified folder.
- mkdir: Creates a new directory (folder) with a given name.
- touch: Creates a new file.
- cp: Copies files or directories from one location to another.
- mv: Moves or renames files and directories.
- rm: Removes (deletes) files or directories
- cat: Displays or concatenates file contents in the terminal.
- chmod: Changes read, write, and execute permissions on files or directories.
