## Day 15 - Linux Terminal Basics (Kali Linux)
Date: Nov 10, 2026

## What I learned
- A Virtual Machine (VM) runs a second computer (like Kali Linux) inside my main laptop.
- The Host is my Windows laptop, and the Guest is Kali Linux.
- The Terminal is the black window where I type commands to control Linux.
- pwd shows my current location, and ls shows my files.
- OverTheWire Bandit is a fun game to practice connecting via SSH and finding hidden passwords.


## What I did
 - I opened my pre-installed Kali Linux inside VirtualBox.
 - My VM uses 2048 MB RAM and 25 GB disk space.
 - I opened the Terminal.
 - I typed pwd and pressed Enter. It showed: /home/kali
 - I typed ls and pressed Enter. It showed my main folders (like Desktop, Documents, Downloads).
 - I took a screenshot of my terminal output.
 - I completed OverTheWire Bandit: Level 0 and Level 1.


 ## New words
 - VM (Virtual Machine): A computer inside my computer.
 - Host: My main laptop OS (Windows).
 - Guest: The inside OS (Kali Linux).
 - ISO: The setup file used to install an OS.
 - Terminal: The app where I type Linux commands.
 - pwd: Shows "where I am" in Linux.
 - ls: Shows "what files are here" in Linux.
 - SSH (Secure Shell): A secure way to connect to a remote computer terminal.


## What was hard
 - Connecting to the Bandit server using the SSH command and finding the password in the readme file.


## Explain in 2 sentences
 - A virtual machine lets me safely practice Kali Linux without changing my Windows laptop. Completing Bandit Levels 0 and 1 helped me practice using SSH and reading files in the Linux terminal.
