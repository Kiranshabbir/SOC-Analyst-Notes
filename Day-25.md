# Day 25 - Malware types
Date: Nov 20, 2026


## 1. What I learned
-  I learned that malware is harmful software built to damage, steal, or control.
-  A virus attaches to a file and spreads when the file is opened or shared.
- A worm spreads by itself across a network, without a person doing anything.
- A trojan hides inside software that looks normal, but is actually harmful.
- Ransomware locks my files and asks for money to unlock them.
- Spyware secretly watches what I do and sends the information to someone else.


## 2. What I did
- I watched videos of malware types.
| Malware | How it spreads | Harm example |
|---------|----------------|--------------|
| Virus | Opening an infected file | Deletes or corrupts files |
| Worm | By itself, across a network | Slows down or crashes a network |
| Trojan | Hides in normal-looking software | Steals passwords |
| Ransomware | Email attachments, bad links | Locks files, demands payment |
| Spyware | Hidden in downloads | Steals personal information |


## 3. New words
- Virus: attaches itself to a file and spreads when the file is opened or shared.
- Worm: spreads by itself across a network, without needing a person to open anything.
- Trojan: hides inside software that looks normal or useful, but is actually harmful.
- Ransomware: locks or encrypts your files and asks for money to unlock them.
- Spyware: secretly watches what you do and sends the information to someone else.
