# Day 13 - Common Ports
Date: Nov 8, 2026

## 1. What I learned
- A port is a number that tells a computer which service (program) should get the data.
- Each common protocol has a standard port number.
- Some ports are secure, and some are not secure (for example, Telnet on 23 is not secure, but SSH on 22 is).

## 3. New words
- Port: a number for a service on a computer.
- FTP = File Transfer Protocol
- SSH = Secure Shell
- SMTP = Simple Mail Transfer Protocol
- RDP = Remote Desktop Protocol
- POP = Post Office Protocol 
- SMB = Server Message Block.
