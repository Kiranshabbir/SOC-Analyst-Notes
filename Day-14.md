## What I learned in this week
- Topology is an arrangement of devices and connections in a network.
- OSI and TCP/IP model: OSI is a u layer model, TCP/IP model is a 4 layer model.
- TCP/UDP: TCP is slow but reliable,UDP is fast but not reliable.
- 3- way handshake is SYN, SYN- ACK, ACK
- DNS is like a phonebook of the internet.
- nslookup is used to find IP from the name.
- HTTP: my browser sends a GET request, and the server sends back a status code, like 200 (OK) or 404 (not found).
- Common ports: each service has a port number, for example HTTP 80, HTTPS 443, SSH 22, DNS 53.
