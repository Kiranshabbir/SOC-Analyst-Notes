Day 3: Windows Files and Folders
Date: October 29,2026


1. What I learned
- A file holds information, like text or a picture.
- A folder holds files. It keeps my work organized.
- A file path is the address of a file on my computer.
- An extension is the ending of a file name, like .txt.

- I watched a YouTube video: "Windows File Explorer for Beginners". It was about how to use File Explorer to find, open, and organize files and folder.

3. New words
- file = a container for information
- folder = a place that holds files
- file path = the address of a file
- extension = the ending of a file name
- hidden file = a file Windows does not show by default
